Wall Generator

Select WALL placeholders. The rough bounding box becomes the wall envelope; the long horizontal axis becomes the wall run.

AZ100 → 25×25 vertical studs @ ≤500, 400 mm panels. NANO → 25×25 horizontal rails @ ≤500. PANEL100 → no steel frame, 1000 mm panels.

Door / Window Types

Placeholders are grouped by name (DOOR 1, WINDOW 2…). Dimensions are clear-opening sizes in millimetres.

IDQtyWidthHeightSillLocationFrame
Frames are built inside the nearest recognised WALL placeholder. Doors start at wall base; windows start at the sill height.

Floor System

Select a FLOOR or BALCONY placeholder. Its footprint becomes the framing boundary.

Perimeter primary frame → evenly distributed secondary beams → finish layer. Cemboard is split to the stock sheet size with FULL/CUT pieces recorded for the BOM. I-sections stay upright whichever direction the beam runs.

Roof System

Mono and Gable use the placeholder footprint. Hip / From Faces reads the rough roof faces inside the group.

Overhang (mm)

Roof columns 100×100; perimeter and main frames 50×100; secondary 30×60. Main rafters try to pass through recognised COLUMN placeholder positions.

Connection Engine

Creates connection nodes between generated structural members. Types and relationships are automated; plate, bolt and weld sizes are editable placeholders.

Rules: I beam ↔ I column → plate + bolts • I beam ↔ SHS100 column → direct weld • secondary I ↔ primary I → bolted plate • roof 50×100 ↔ SHS100 → direct weld • upper SHS100 column ↔ deck/I floor → base plate (manual pairing).
NameRuleABMode
Engineering boundary: these are modelling representations. Plate thickness, bolt count/diameter, edge distance and weld size are not a structural design approval.
